# Сторонние библиотеки и фреймворки

## Линтеры, статические анализаторы, форматтеры

[mypy](https://mypy.readthedocs.io/en/stable/) — статический анализатор кода.

[Ruff](https://github.com/astral-sh/ruff) — быстрый линтер и форматтер кода, написанный на Rust.

[Flake8](https://flake8.pycqa.org/en/latest/) — линтер, который сканирует код на наличие ошибок, проблем со стилем и цикломатической сложностью.

[Pylint](https://pypi.org/project/pylint/) — линтер и статический анализатор кода.

[Black](https://github.com/psf/black) — форматтер кода для приведения проекта в соответствие с `PEP8`.

## Юнит тесты

В питоне есть стандартный модуль `unittest` для покрытия кода юнит-тестами.
Но если вам не хватает его функциональности, посмотрите в сторону фреймворка [pytest](https://docs.pytest.org/en/7.4.x/).

## Веб-фреймворки

[Flask](https://flask.palletsprojects.com/en/3.0.x/) — легковесный веб-фреймворк с минималистичным синтаксисом.

[Django](https://www.djangoproject.com/) — чрезвычайно богатый на возможности мощный веб-фреймворк.

[FastAPI](https://fastapi.tiangolo.com/) — высокопроизводительный простой веб-фреймворк для быстрого создания API.

## Анализ данных

[NumPy](https://numpy.org/) — библиотека, в которой эффективно реализованы многомерные массивы и математические операции над ними.

[Pandas](https://pandas.pydata.org/) — библиотека для обработки и анализа табличных данных и временных рядов: фильтрации, сортировки, модификации...

[SciPy](https://scipy.org/) — библиотека для научных и инженерных расчетов.

## Визуализация данных

[Matplotlib](https://matplotlib.org/) — библиотека для построения любых видов графиков и статической, анимированной и интерактивной визуализации данных.

[Seaborn](https://seaborn.pydata.org/) — библиотека для визуализации данных, базирующаяся на Matplotlib.

## Машинное обучение

[Keras](https://keras.io/) — библиотека для глубокого обучения (deep learning), которая хорошо подходит новичкам в мире ML.

[TensorFlow](https://www.tensorflow.org/) — фреймворк для машинного обучения от команды Google Brain.

[Scikit-learn](https://scikit-learn.org/) — библиотека для машинного обучения, базирующаяся на NumPy, SciPy, и Matplotlib.

[PyTorch](https://pytorch.org/) — фреймворк для работы с моделями машинного обучения, в том числе для компьютерного зрения и обработки естественного языка.

[NLTK](https://www.nltk.org/) — библиотека для обработки текстов на естественном языке (Natural Language Toolkit).

## Компьютерное зрение

[OpenCV](https://opencv.org/) — библиотека, в которой реализовано множество алгоритмов компьютерного зрения, обработки изображений и видео.
